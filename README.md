# EaglercraftX 1.8 离线版

基于 [EaglercraftX](https://github.com/lax1dude/eaglercraft) 的 Minecraft 1.8.8 浏览器离线版本。

## 功能特性

- 🎮 在浏览器中直接游玩 Minecraft 1.8.8
- 📴 完全离线运行，无需网络连接
- 🌐 支持中文界面
- ⚡ 零配置，开箱即用

## 使用方法

直接在本项目提供的本地服务器上打开 `index.html` 即可开始游戏：

```
http://localhost:8080/
```

或使用任意静态网站托管服务部署此项目。

## 技术栈

- EaglercraftX (Minecraft 1.8.8 WebGL 移植)
- 纯前端实现，无需后端服务
- 所有资源已内嵌至单个 HTML 文件

## 许可证

本项目基于 EaglercraftX 项目，遵循其原始许可证。
